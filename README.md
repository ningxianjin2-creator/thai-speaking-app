# 泰语开口说 · 第一版

这是一个面向手机浏览器的泰语日常口语学习网页。

## 当前功能
- 中文意思、拉丁字母转写和中文近似发音提示
- 浏览器泰语语音合成：正常、慢速、重复播放
- 问候、餐厅、出行、购物、求助等场景课程
- 标记已学会，并将学习进度保存在当前浏览器
- 纯静态网页，无需后端或数据库

## 运行
直接打开 `index.html`，或将其部署到任意静态网站托管服务。

## 语音说明
目前使用浏览器/设备提供的语音合成，不是真人录音。能否使用泰语语音取决于设备和浏览器是否安装泰语语音数据。
